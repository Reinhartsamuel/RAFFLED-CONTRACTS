## 6. Outreach playbook

1. **Channel:** X DM first (most Base teams live there); Farcaster DM second; Discord only if you have a warm intro. Use the account you plan to keep for the product.
2. **Who to DM:** founder / CMO / bizdev. Find via project site → team page, or Docs → contributors. For Aerodrome: team is pseudonymous — DM their official X account directly. For Virtuals: community/biz account. For Zora: @zora account or their "based" team members.
3. **Cadence:** 3–4 DMs/day, Tier 1 first, personalization hook each time. Do NOT blast 15 identical DMs in one hour (ban risk + looks like spam).
4. **Promise discipline:** free = free. No fees, no strings. You want: hosted raffle + permission to publish a case study + a testimonial line.
5. **Track:** replies / hosted raffles / second-raffle intent. Decision gate (from the plan): ≥30% reply rate AND ≥3 hosted = B2B signal is real → keep going. Dead silence after Tier 1 + Tier 2 → the wedge is weak, pivot discussion with data.
6. **Proof of life:** before DMing each project, check their X activity in the last 2 weeks (the "no dead projects" rule — one glance at their feed).

## 7. What you're selling them (recap for the call)

- **The problem:** communities accuse projects of rigged giveaways; projects can't prove fairness.
- **Your solution:** free entries signed by the project (allowlist), winner by Chainlink VRF, prize self-custodied, verification page showing request → random word → winner.
- **Their cost:** a wallet list + one signature script run (or you run it for them).
- **Your ask:** the case study + testimonial. Nothing else.
